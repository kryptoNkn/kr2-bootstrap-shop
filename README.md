# SIP Coffee

Веб-сайт спешелти-кофейни **SIP Coffee**, расположенной по адресу: Москва, Газетный переулок, 3.

Проект представляет собой многостраничное статическое веб-приложение из четырёх страниц: главной страницы, каталога напитков и десертов, страницы контактов и корзины с оформлением заказа.

Приложение работает без этапа сборки и не требует установки дополнительных зависимостей. Для запуска достаточно открыть HTML-файлы в браузере или использовать локальный HTTP-сервер.

## Запуск проекта

Клонируйте репозиторий и перейдите в его корневую директорию.

Запустите локальный HTTP-сервер:

```bash
python3 -m http.server 8765
```

Откройте сайт в браузере:

[http://127.0.0.1:8765](http://127.0.0.1:8765)

Также можно открыть `index.html` непосредственно в браузере.

**Примечание:** для загрузки веб-шрифтов, Bootstrap, Bulma и отображения карты Яндекса требуется подключение к интернету. Изображения и графические материалы хранятся локально в проекте.

## Страницы приложения

| Файл | Описание |
| --- | --- |
| `index.html` | Главная страница с информацией о кофейне, преимуществами, популярными позициями и специальными предложениями. |
| `menu.html` | Каталог напитков и десертов с фильтрацией по категориям и добавлением товаров в корзину. |
| `contacts.html` | Информация о кофейне, адрес, график работы, интерактивная карта, отзывы и форма обратной связи. |
| `cart.html` | Управление составом заказа, применение промокодов, выбор способа получения и времени приготовления, оформление заказа и просмотр истории. |

## Функциональные возможности

### Каталог
- Разделение товаров на категории: кофе, чай, холодные напитки и десерты.
- Фильтрация товаров по категориям.
- Выбор объёма напитка: 200 или 300 мл.
- Настройка дополнительных опций: альтернативное молоко, сироп и дополнительный эспрессо-шот.
- Добавление выбранных позиций в корзину.

### Корзина и оформление заказа
- Изменение количества товаров и удаление отдельных позиций.
- Автоматический расчёт стоимости заказа.
- Поддержка промокодов:
  - `SIP20` — скидка 20%;
  - `EVENING` — скидка 10%;
  - `SIPCOFFEE` — скидка 15%.
- Выбор способа получения заказа:
  - самовывоз — бесплатно;
  - доставка — 350 ₽.
- Выбор времени приготовления: как можно скорее, через 20, 40 или 60 минут.
- Автоматический расчёт итоговой стоимости с учётом скидки и стоимости доставки.
- Сохранение оформленных заказов в истории.
- Возможность повторного оформления предыдущего заказа.

### Хранение данных
Корзина и история заказов сохраняются в `localStorage` браузера. Данные остаются доступными при переходе между страницами и повторном открытии сайта в том же браузере.

## Технологический стек

| Технология | Назначение |
| --- | --- |
| HTML5 | Структура и семантическая разметка страниц. |
| CSS3 | Стилизация интерфейса и адаптация под различные размеры экранов. |
| JavaScript | Логика каталога, фильтрации, корзины, промокодов и обработки форм. |
| Bootstrap 5.3 | Сетка, адаптивная раскладка, утилиты отступов и выравнивания, модальные окна, уведомления, мобильная навигация и валидация форм. |
| Bulma 0.9 | Дополнительные CSS-компоненты и стили интерфейса. |

Дополнительно используются:
- **Syne** и **Plus Jakarta Sans** — веб-шрифты для оформления интерфейса.
- **Яндекс Карты** — отображение местоположения кофейни.

### Собственные ресурсы

- `css/custom.css` — пользовательская система стилей, определяющая визуальную идентичность SIP Coffee: цветовую палитру, типографику, сетку и оформление компонентов.
- `js/app.js` — клиентская логика приложения: работа с каталогом, фильтрация, управление корзиной, применение промокодов и обработка форм.

Bootstrap и Bulma подключаются через CDN. Основное визуальное оформление реализовано собственными стилями проекта.
